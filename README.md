## Завдання № 1

Не використовуючи стандартні математичні функції, розрахувати суму ряду:

$$
S = \sum_{n=0}^{N} (-1)^n \frac{a^n}{n!}
$$

[Файл task1.c](https://github.com/katyavradii/--1/blob/main/task1.c)

В цій частині коду ми оголошуємо змінні та зчитуємо значення дійсного числа `a` та кількості ітерацій `N` з клавіатури:

```
    //оголошення змінних
    double a;
    int N;
    //введення даних 
    printf("Enter a number: ");
    scanf("%lf", &a);
    printf("Enter the number of iterations: ");
    scanf("%d", &N);

```

В цій частині коду ми обчислюємо суму ряду за рекурентною формулою без використання бібліотеки `<math.h>`:

```
    double sum = 0.0;
    double term = 1.0; 

    for (int n = 0; n < N; n++) {
        sum += term;
        term = -term * a / (n + 1); 
    }

```

Замість окремого обчислення степеня $a^n$ та факторіалу $n!$, кожен наступний член ряду виражається через попередній множенням на $-\frac{a}{n + 1}$:

```
    term = -term * a / (n + 1);

```

В кінці програми виводимо підсумковий результат суми:

```
    printf("Sum: %lf\n", sum);

```

## Завдання № 2

[Файл task2.c](https://github.com/katyavradii/--1/blob/main/task2.c)

В цьому завданні необхідно створити статичний одномірний масив цілих чисел, реалізувати сортування елементів за спаданням у вигляді окремої функції `sort` типу `void`, а також вивести масив до і після сортування на екран за допомогою окремої функції `print_array`.

Прототипи функцій з коментарями:

```
/** 
 * @brief Виводить елементи одновимірного цілочисельного масиву в стандартний потік виведення.
 * 
 * @param arr Масив чисел.
 * @param size Кількість елементів у масиві.
 */
void print_array(const int arr[], int size);

/** 
 * @brief Сортує елементи одновимірного цілочисельного масиву за спаданням.
 * 
 * 
 * @param arr Масив чисел.
 * @param size Кількість елементів у масиві.
 */
void sort(int arr[], int size);

```

Головна функція `main`, ініціалізація статичного масиву та послідовний виклик функцій:

```
int main() {
    int array[10] = {12, -5, 43, 0, 88, 19, -21, 7, 100, 34};

    printf("Original array:\n");
    print_array(array, 10);

    sort(array, 10);

    printf("\nSorted array:\n");
    print_array(array, 10);

    return 0;
}

```

Функція виведення масиву в консоль:

```
void print_array(const int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

```

Функція сортування масиву за спаданням:

```
void sort(int arr[], int size) {
    for (int i = 0; i < size - 1; i++) {
        for (int j = 0; j < size - i - 1; j++) {
            if (arr[j] < arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

```
